# 🌐 Personal Portfolio Website

This is my personal portfolio website built using **HTML**, **CSS**, and a small amount of **JavaScript**. It showcases my background, education, technical skills, projects, and contact information in a clean and modern interface.

The website features a dark blue glassmorphism-inspired design with smooth hover animations, a sticky navigation bar, responsive layouts, and interactive project cards. It serves as a central place to present my work and document my journey as a Computer Science student and aspiring Frontend Developer.

## ✨ Features

- Modern dark-themed UI with glassmorphism effects
- Sticky navigation bar with smooth scrolling
- About Me and Education sections
- Skills section with technology cards
- Interactive project cards with expandable descriptions
- Contact section with quick access to social platforms
- Responsive design for desktop, tablet, and mobile devices
- Clean and organized code structure

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Purpose

This portfolio was created to showcase my projects, demonstrate my frontend development skills, and continuously improve my web development abilities as I learn new technologies.
